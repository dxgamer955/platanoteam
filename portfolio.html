Built for the way I work.

Engines, image utilities, and production tools made in-house to support Platano Team games, artwork pipelines, and development workflows.

Platano Engine

A game engine for developing Windows and Linux games at Platano Team using Raylib.

Nitratano Engine

An in-house engine based on Nitro Engine for developing Nintendo DS homebrew projects at Platano Team.

Dark Light Pixelixer

A pixel-art production utility created for Dark Light image processing and visual workflow experiments.

Dark Light Pixelixer PRO

An expanded version of the Pixelixer workflow for more advanced Dark Light art preparation.

DX Remove BG

A custom background-removal helper for preparing transparent assets and faster image cleanup.

Dark Light Scene Organizer

A production organizer for Dark Light scene assets, references, and image-based pipeline work.

PDN Layer Exporter

A Paint.NET-focused helper for exporting layered artwork into usable production assets.

Ultimate Dark Light Dev Tool

A unified evolution of Dark Light Pixelixer PRO and DX Remove BG, expanded with more options and workflow improvements.
